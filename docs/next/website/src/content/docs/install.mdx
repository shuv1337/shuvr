---
title: Install Shuvr
description: Install, update, and verify Shuvr on Linux and macOS.
---

Shuvr ships as a single binary for Linux and macOS.

## Install

Run the installer:

```bash
curl -fsSL https://github.com/shuv1337/shuvr/install.sh | sh
```

The installer downloads the right release binary for your platform and places it on your PATH.

## Install with Homebrew

If you already use Homebrew:

```bash
brew install shuvr
```

## Verify

Start Shuvr:

```bash
shuvr
```

If your shell cannot find `shuvr`, restart the terminal or check that the install directory is on your PATH.

## Update

Shuvr checks for new releases and notifies you in the app. You can update manually:

```bash
shuvr update
```

`shuvr update` is for installs managed by Shuvr's own installer. Homebrew and Nix installs are updated through those package managers instead.

By default, `shuvr update` installs the new binary and leaves compatible running sessions alone, or asks before stopping sessions that must restart. To opt into experimental live server handoff for supported running sessions, run:

```bash
shuvr update --handoff
```

Live handoff does not apply to Homebrew or Nix package-manager updates. For those installs, update with the package manager, then restart any running Shuvr servers that need the new binary.

## Install with Nix

If you already use Nix, Shuvr provides a flake that builds Shuvr from source:

```bash
nix run github:shuv1337/shuvr/v0.x.y
nix build github:shuv1337/shuvr/v0.x.y
nix profile install github:shuv1337/shuvr/v0.x.y
```

Replace `v0.x.y` with the latest release tag. You can omit the tag to track `master`, but release tags are recommended for normal installs.

The flake also exposes a development shell:

```bash
nix develop github:shuv1337/shuvr
```

Update through the same Nix workflow you used to install Shuvr. For a profile install, list your profile entries and upgrade the Shuvr entry:

```bash
nix profile list
nix profile upgrade <index-or-name>
```

If Shuvr is an input in your own flake, update that input and rebuild your system, Home Manager, or development environment:

```bash
nix flake update shuvr
```

## Download manually

You can also download a binary from [GitHub releases](https://github.com/shuv1337/shuvr/releases).

Choose the asset that matches your system:

| System | Asset |
| --- | --- |
| Linux x86_64 | `shuvr-linux-x86_64` |
| Linux aarch64 | `shuvr-linux-aarch64` |
| macOS Intel | `shuvr-macos-x86_64` |
| macOS Apple silicon | `shuvr-macos-aarch64` |

Make it executable and move it somewhere on your PATH.

```bash
chmod +x shuvr-linux-x86_64
mv shuvr-linux-x86_64 ~/.local/bin/shuvr
```

## Requirements

Shuvr supports Linux and macOS. Native Windows support is not available yet; use Shuvr inside WSL for now.
